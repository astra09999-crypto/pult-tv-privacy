Политика конфиденциальности «Пульт TV» для Huawei AppGallery

Дата: 13 октября 2026 года. Разработчик: Страшко Андрей. Поддержка: astra077@inbox.ru.

Локальное управление

Приложение обнаруживает совместимые телевизоры в локальной сети и отправляет команды выбранному телевизору. На телефоне сохраняются IP-адреса и сведения о телевизорах, настройки, избранные приложения и данные сопряжения. Секреты сопряжения шифруются ключом Android Keystore. Данные приложения не копируются в резервную копию и не отправляются разработчику.

Текст и медиа

Введённый текст передаётся выбранному телевизору. При выборе файла через системный диалог приложение создаёт временную копию в своём закрытом кэше и предоставляет её выбранному IP-адресу телевизора по случайной временной ссылке в Wi-Fi сети. Сервер закрывается при уходе приложения в фон; временная копия удаляется при замене файла или завершении экземпляра приложения. После аварийного завершения копия может остаться в закрытом кэше до его очистки. Не отправляйте конфиденциальные материалы в недоверенной сети: некоторые телевизоры используют незашифрованные локальные протоколы.

Если пользователь отправляет прямую HTTP(S)-ссылку, телевизор запрашивает её у указанного сервера. Запускаемые на ТВ сторонние приложения и медиа-сервисы обрабатывают данные по собственным политикам.

Видео YouTube

Только по действию пользователя приложение получает у выбранного телевизора идентификатор экрана YouTube и отправляет его вместе с идентификатором выбранного ролика в сервисы YouTube по HTTPS. Для управления воспроизведением создаётся временный сеанс с случайным идентификатором пульта. Токены этого сеанса не сохраняются на телефоне и не передаются разработчику. Воспроизведение и обработка этих данных выполняются сервисом YouTube по его правилам. Приложение не извлекает и не скачивает потоки YouTube.

Разрешения

Доступ к интернету, состоянию сети, Wi-Fi и multicast нужен для локального обнаружения и управления. Вибрация используется для отклика кнопок. Доступ к файлу ограничен выбранным пользователем URI; приложение не запрашивает доступ ко всему накопителю, контактам, местоположению, микрофону или камере.

Bluetooth-пульт

Дополнительный режим использует стандартный профиль HID Device: телефон передаёт выбранному телевизору клавиатурные и медиаклавиши. Разрешение «Устройства поблизости» запрашивается только при выборе этого режима. По действию пользователя системный диалог может сделать телефон видимым для сопряжения на 180 секунд. Имя и Bluetooth-адрес выбранного ТВ сохраняются локально. Данные не передаются разработчику. Приложение не сканирует Bluetooth-окружение и не получает геолокацию.

Аналитика и удаление

Основной пульт не требует регистрации. Собственного сервера сбора пользовательских данных у разработчика нет. Сведения о рекламе и покупках AppGallery приведены ниже. Удалите сохранённый ТВ в списке устройств, чтобы удалить его данные приложения и избранное. Системное Bluetooth-сопряжение Android удаляется отдельно в настройках Bluetooth телефона. Все данные приложения и кэш можно удалить в настройках приложения Android или при удалении приложения.

Обращение в поддержку

Если вы сами пишете на email поддержки, разработчик получает адрес отправителя и сведения, которые вы включили в обращение. Не отправляйте токены сопряжения, ключи, пароли или личные медиа. Данные письма используются для ответа и устранения описанной проблемы. По вопросам удаления обращения свяжитесь с поддержкой.

Версия Huawei AppGallery: покупки

В версии AppGallery доступны две отдельные разовые покупки Huawei In-App Purchases: отключение рекламы и Pro. Pro также отключает рекламу. Подписок нет. Huawei обрабатывает данные аккаунта Huawei, устройства, сети, региона и оплаты по своим правилам. Приложение получает подписанные сведения о продукте, заказе и токене покупки для проверки подлинности и восстановления прав. Подтверждённые квитанции хранятся на телефоне в зашифрованном виде. Данные банковской карты приложение не получает и не сохраняет. Бесплатное управление телевизором доступно без аккаунта Huawei.

Petal Ads / Huawei Ads

Рекламный SDK инициализируется для показа баннера только после вашего согласия в разделе «Реклама и конфиденциальность» настроек и при отсутствии права отключения рекламы. В этой версии запрашивается только неперсонализированная реклама. Отказ и отзыв согласия не ограничивают бесплатное управление телевизором. После покупки отключения рекламы или Pro новые рекламные запросы прекращаются, баннер удаляется.

Получатель данных рекламного сервиса — Huawei Software Technologies Co., Ltd. SDK может обрабатывать рекламные идентификаторы OAID/ODID, сведения об устройстве и ОС, приложении и его использовании, параметры сети и оператора, IP-адрес, доступные параметры Wi-Fi и сведения о взаимодействии с рекламой; согласно документации SDK возможна обработка доступных сведений датчиков устройства. Эти данные используются для доставки, измерения и защиты рекламных объявлений. Отсутствие персонализации не означает отсутствие передачи данных. Содержание и сроки обработки Huawei определяются её действующей политикой.

Приложение не запрашивает геолокацию для рекламы, не передаёт её в рекламный запрос и не предоставляет SDK общий доступ к накопителю, микрофону, камере, телефону или полному списку установленных приложений. Баннер не имеет доступа к выбранным для ТВ файлам, полям текста и секретам сопряжения. Отдельные аналитические SDK разработчика не добавлены. Интегрированные библиотеки HMS могут обрабатывать техническую диагностику своих сервисов по правилам Huawei.

Для отзыва согласия откройте настройки приложения → «Реклама и конфиденциальность» → «Отказаться». Управление рекламным идентификатором также доступно в настройках устройства, если его ОС предоставляет эту возможность. При очистке данных согласие сбрасывается; перед новой рекламной обработкой его нужно предоставить заново. Удаление локальных данных не удаляет покупки из аккаунта Huawei.
